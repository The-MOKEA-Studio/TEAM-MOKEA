# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/The-MOKEA-Studio/TEAM-MOKEA/security/advisories/new)
for this repository. Include the affected version, steps to reproduce, and
impact. Please do not publish exploit details before a fix is available.

## Supported versions

The latest version on the `master` branch is supported.
